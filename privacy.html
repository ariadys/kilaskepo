Privacy Policy

Last updated: 15 October 2026

1. Summary

The Kilas Kepo Publisher ("the app") is a private desktop tool used only by the owner of the Kilas Kepo accounts to post their own content. It does not collect data from the public, does not track visitors, and does not sell or share personal data.

2. Data the app receives from TikTok

When the account owner authorizes the app with TikTok Login Kit, the app receives:

  • an access token and a refresh token, used only to upload videos to the authorizing account;
  • the account's open ID and display name (scope user.info.basic), used to confirm the correct account is connected;
  • the account's posting options from TikTok (username, allowed privacy levels, and whether comments, duets, and stitches are enabled), used to set the options of each upload;
  • the processing status of each upload and, for public posts, the post ID, used to confirm the upload succeeded.

The app uses the video.publish (or video.upload) scope only to send the owner's own videos and captions to the owner's account. It does not read other users' profiles, videos, comments, messages, or followers.

3. Where data is stored

Tokens and post status are stored only on the owner's own computer, in local configuration and state files. They are not uploaded to any server operated by the app. Videos are sent directly from that computer to TikTok.

4. Sharing

Data is shared only with the platform it belongs to (for example, videos and captions are sent to TikTok to be published). No data is sold, rented, or used for advertising.

5. Retention and deletion

Tokens are kept until the owner disconnects the app or they expire. Access can be revoked at any time in TikTok under Settings and privacy → Security → Apps and services permissions, after which the stored tokens stop working and are removed from the owner's computer. Published posts can be deleted in the TikTok app.

6. Children

The app is not intended for, and does not knowingly process data from, anyone under 18.

7. This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visitor IP addresses for security, as described in the GitHub Privacy Statement.

8. Changes

This policy may be updated from time to time. The date at the top of this page shows when it last changed.
